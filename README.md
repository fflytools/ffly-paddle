# FFLY Paddle – Open Design Files

Design files for the **FFLY** morse code paddle, designed and made by **FireflyTools (FFLY Tools)**.

These files are shared so that you can study, modify and make your own parts and variants of the FFLY paddle for **non-commercial** use.

## What's included

- A **STEP assembly** of the FFLY paddle.
- Every component is named in the assembly. Fasteners follow a consistent naming scheme (for example `M2.5_SetScrew_10mm`), so the assembly tree doubles as a bill of materials.

## What's not included

- CAM files, toolpaths, fixtures and machining setups.

## Dimensions are nominal

The geometry is nominal. The original paddle is machined from aluminium except for the insulator, 3D printed in ASA.  Adjust clearances, fits and wall thicknesses for your own process and material, and test before relying on any part.
